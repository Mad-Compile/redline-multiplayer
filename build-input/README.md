# REDLINE Android build input

Upload the supplied `REDLINE_v0.5.0_GitHub_Actions_Build_Source.zip` into this folder on branch `prototype/v0.5.0-android-practice`.

The Android APK workflow starts automatically when that exact ZIP path is pushed. The archive should contain the Godot project root (`project.godot`, `scripts/`, `assets/`, `scenes/`, `services/`, and `export_presets.cfg`). Do not upload an APK here.
